
# Geometric Library

## Описание проекта

Проект представляет собой библиотеку на Python
для вычисления площади и периметра различных
геометрических фигур.

## Возможности

Программа позволяет вычислять:

- Площадь круга и длину окружности.
- Площадь и периметр прямоугольника.
- Площадь и периметр квадрата.
- Площадь и периметр треугольника.

## Структура проекта

| Файл | Описание |
|------|----------|
| circle.py | Вычисления для круга |
| rectangle.py | Вычисления для прямоугольника |
| square.py | Вычисления для квадрата |
| triangle.py | Вычисления для треугольника |
| docs/documetation.md | Документация проекта |
| test_geometry.py | Модульные тесты для четырёх фигур |

## Использование

Для работы требуется Python 3.
Дополнительные библиотеки устанавливать не нужно.

### Пример вычисления площади круга

```python
from circle import area

print(area(2))
```

Результат:

```text
12.566370614359172
```

### Пример вычисления периметра квадрата

```python
from square import perimeter

print(perimeter(5))
```

Результат:

```text
20
```
