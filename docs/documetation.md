#Документация проекта 1

##1 Общее описание

Проект проект представляет собой программы на пайтон , в которые нужны для вычислений периметров и площадей разных фигур

##2 Описание функций 

###2.1 Файл circle.py

#### Функция area(r)

Функция получает на вход радиус круга
и возвращает его площадь.

Параметры:
	 r (float) — радиус круга.
Возвращаемое значение:
	 float — площадь круга.
Пример вызова:
	 area(2)
Результат:
	 12.566370614359172

#### Функция perimeter(r)

Функция получает на вход радиус окружности
и возвращает её длину.

Параметры:
	 r (float) — радиус окружности.
Возвращаемое значение:
	 float — длина окружности.
Пример вызова:
	 perimeter(2)
Результат:
	 12.566370614359172

###2.2 Файл square.py

#### Функция area(a)

Функция вычисляет площадь квадрата.

Параметры:
	 a (float) — длина стороны квадрата
Возвращаемое значение:
	 float — площадь квадрата
Пример вызова:
	 area(5)
Результат:
	 25

#### Функция perimeter(a)

Функция вычисляет периметр квадрата
Параметры: 
	a (float) — длина стороны квадрата
Возвращаемое значение:
	 float — периметр квадрата
Пример вызова:
	 perimeter(5)
Результат:
	 20

###2.3  Файл triangle.py

#### Функция area(a, h)

Функция вычисляет площадь треугольника по основанию и высоте
Параметры:
	 a (float) — длина основания треугольника
	 h (float) — высота треугольника
Возвращаемое значение:
	 float — площадь треугольника
Пример вызова:
	 area(6, 4)
Результат:
	 12

#### Функция perimeter(a, b, c)

Функция вычисляет периметр треугольника
Параметры:
	 a (float) — длина первой стороны
	 b (float) — длина второй стороны
	 c (float) — длина третьей стороны
Возвращаемое значение:
	 float — периметр треугольника
Пример вызова:
	 perimeter(3, 4, 5)
Результат:
	 12

###2.4 Файл rectangle.py

#### Функция area(a,b)

Функция вычисляет площадь прямоугольника.

Параметры:
         a (float) — длина стороны прямоугольника
	b (float) — длина стороны прямоугольника
Возвращаемое значение:

Пример вызова:
         area(5,2)
Результат:
         10

#### Функция perimeter(a,b)

Функция вычисляет периметр прямоугольника
Параметры:
        a (float) — длина стороны прямоугольника
	b (float) — длина стороны прямоугольника
Возвращаемое значение:
         float — периметр прямоугольника
Пример вызова:
	perimeter(2,3)
Результат:
	10
