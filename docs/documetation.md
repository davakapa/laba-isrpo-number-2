#Документация проекта 1

##1 Общее описание

Проект проект представляет собой программы на пайтон , в которые нужны для вычислений периметров и площадей разных фигур

##2 Описание функций 

###2.1 Файл circle.py

#### Функция area(r)

Функция получает на вход радиус круга
и возвращает его площадь.

Параметры: r (float) — радиус круга.
Возвращаемое значение: float — площадь круга.
Пример вызова: area(2)
Результат: 12.566370614359172

#### Функция perimeter(r)
Функция получает на вход радиус окружности
и возвращает её длину.

Параметры: r (float) — радиус окружности.
Возвращаемое значение: float — длина окружности.
Пример вызова: perimeter(2)
Результат: 12.566370614359172
